## 🏛️ co.work Nedir? (About co.work)

**co.work**, yazılım geliştirme sürecini otonom uzman alt ajanlardan (subagents) oluşan dinamik bir kadroyla yöneten, yerel (local-first) ve gizlilik odaklı bir masaüstü mühendislik stüdyosudur.

* **Çoklu Ajan Koordinasyonu:** Baş Orkestratör (Hugo) liderliğinde; Sistem Mimarı, Frontend Geliştirici, Backend Geliştirici, Veritabanı Mühendisi, Güvenlik Uzmanı ve Bağımsız Denetçilerden oluşan tam kadro bir yazılım ofisi.
* **Karşıt Doğrulama Kapıları (Adversarial Quality Gates):** `code-reviewer` ve `appsec` bağımsız denetçileri VETO yetkisine sahiptir; standartları karşılamayan hiçbir kod teslim edilemez.
* **Gemini & Antigravity Gücü:** Google Gemini 3.8 Flash ve Gemini 3.1 Pro başta olmak üzere, yerel ve BYOK CLI motorlarıyla yüksek performanslı kod üretimi.
* **Görsel Ofis Arayüzü:** 2D piksel ofis katında çalışan uzman ajanlar, gerçek zamanlı durum göstergeleri ve canlı terminal takibi.
* **Fit-to-Viewport & Anti-AI-Slop:** Aşırı karmaşık veya basmakalıp AI şablonları yerine yüksek işçilik standartları, sıfır kaydırma (zero-scroll) modalları ve savunmacı mühendislik ilkeleri.

## 🚀 Başlarken (Getting Started)

### Gereksinimler
- Node.js 20+
- npm veya pnpm
- [Antigravity CLI](https://github.com/google/antigravity) (`agy`) veya Gemini CLI

### Kurulum ve Geliştirme

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme modunda çalıştırın
npm run dev

# Uygulamayı derleyin
npm run build

# Masaüstü paketini oluşturun (macOS)
npm run dist:mac
```

## 🛡️ Güvenlik ve Gizlilik (Security & Privacy)

- **%100 Yerel Depolama:** Proje kodlarınız, ajan hafızaları ve görev tahtaları yalnızca yerel makinenizde (`~/co.work`) saklanır.
- **Harici Telemetri Yok:** Üçüncü parti takip kodları veya dışa bağımlı telemetri içermez.
- **Güvenli API Anahtarı Yönetimi:** BYOK anahtarları işletim sistemi güvenliğinde saklanır ve asla arayüze geri okunamaz.
